# Design — UX и визуальный дизайн FitnessAI

> Этот файл описывает все дизайн-решения бота: структуру экранов, форматирование сообщений, tone of voice, навигацию и визуальный язык.

## Для агентов
- При добавлении нового хендлера — проверяй, соответствует ли его вывод правилам форматирования ниже
- При изменении системного промпта — сверяйся с разделом «Tone of Voice»
- Все новые inline keyboard'ы — по шаблонам из раздела «Компоненты»
- При добавлении нового сценария — описывай его экран в разделе «Экраны»

---

## 1. Принципы дизайна

| Принцип | Как реализуется |
|---|---|
| **Ясность** | Один экран — одно действие. Никогда не задаём два вопроса сразу |
| **Скорость** | Критичные ответы (запись еды, лога) — без лишних подтверждений |
| **Эмпатия** | Бот говорит как личный тренер, не как робот |
| **Предсказуемость** | Одинаковая навигация везде: 🏠 Главное меню всегда доступно |
| **Лёгкость** | Нет длинных инструкций — только нужное, в нужный момент |

## 2. Tone of Voice

**Персонаж:** Личный AI-тренер. Профессиональный, но дружелюбный. Мотивирует без фальши.

**Правила языка:**
- Обращение на **«ты»**, имя пользователя там, где уместно
- Короткие предложения. Максимум 2–3 строки на мысль
- Эмодзи как визуальные маркеры — не декор, а навигация
- Никогда не пишем «Обрабатываю ваш запрос...» — только живые фразы
- Успех → энергия и конкретика: не «Отлично!», а «+1 тренировка в копилку 💪»
- Ошибка → спокойно и с выходом: не «Ошибка», а «Не смог разобрать — попробуй написать иначе»

**Примеры tone:**

```
✅ Правильно:
"День закрыт! 2 450 ккал из 2 600 — почти идеально, Асан 🎯"

❌ Неправильно:
"Ваши данные о питании за сегодня успешно получены и обработаны."
```

```
✅ Правильно:
"Не нашёл такое упражнение. Попробуй написать по-другому?"

❌ Неправильно:
"Ошибка: упражнение не найдено в базе данных."
```

## 3. Форматирование сообщений (Telegram Markdown)

### 3.1 Иерархия текста

```
*Заголовок блока* — жирный, всегда с эмодзи-маркером
Обычный текст — основная информация
_Подсказка или уточнение_ — курсив, мелкий контекст
`значение` — числа, команды, ключевые данные
```

### 3.2 Структура типового ответа агента

```
{эмодзи} *Заголовок*

Основная информация (2–4 строки максимум)

_Подсказка или следующий шаг_
```

### 3.3 Структура карточки плана тренировки

```
🏋️ *Тренировка на сегодня — {день}*

*Разминка (5 мин)*
• Прыжки на месте — 2×30 сек
• Круговые движения руками — 1 мин

*Основная часть*
1. Приседания — 4×12 ◦ отдых 60 сек
2. Отжимания — 3×10 ◦ отдых 45 сек
3. Планка — 3×40 сек

*Заминка (5 мин)*
• Растяжка квадрицепсов — 30 сек каждая нога

⏱ Общее время: ~45 мин
🔥 Примерный расход: 320 ккал
```

### 3.4 Структура карточки плана питания

```
🥗 *План питания на день*
_Норма: 2 600 ккал · Б 160г · Ж 72г · У 290г_

*Завтрак* (~520 ккал)
• Овсянка варёная 200г — 176 ккал · Б 6г · Ж 4г · У 30г
• Яйцо варёное 2 шт (110г) — 157 ккал · Б 13г · Ж 11г · У 1г
• Банан 1 шт (120г) — 107 ккал · Б 1г · Ж 0г · У 27г

*Обед* (~780 ккал)
• Куриная грудка 200г — 220 ккал · Б 46г · Ж 2г · У 0г
• Гречка варёная 200г — 254 ккал · Б 9г · Ж 2г · У 50г
• Огурец + помидор 150г — 27 ккал · Б 1г · Ж 0г · У 5г

*Ужин* (~620 ккал)
• Лосось 150г — 297 ккал · Б 29г · Ж 19г · У 0г
• Картофель запечённый 200г — 154 ккал · Б 4г · Ж 0г · У 35г
• Брокколи 150г — 51 ккал · Б 5г · Ж 1г · У 8г

*Перекусы* (~680 ккал)
• Творог 5% 200г — 188 ккал · Б 24г · Ж 10г · У 7г
• Орехи грецкие 30г — 196 ккал · Б 5г · Ж 20г · У 3г
```

### 3.5 Структура записи прогресса

```
📊 *Прогресс записан*

Вес: `78.5 кг` (−0.5 кг с прошлого раза)
Дата: 18 мая 2026

_Следующее взвешивание — через 7 дней. Держи темп! 💪_
```

### 3.6 Структура дневного итога питания

```
🍽 *Итог за сегодня*

Калории:  `1 840 / 2 600 ккал` ████████░░ 71%
Белки:    `112 / 160г`          ███████░░░ 70%
Жиры:     `58 / 72г`            ████████░░ 81%
Углеводы: `201 / 290г`          ███████░░░ 69%

_Ещё ~760 ккал до нормы. Не забудь про ужин!_
```

> Прогресс-бар из символов `█░` — работает в любом Telegram-клиенте без картинок.

## 4. Эмодзи-система (визуальный язык)

Эмодзи выполняют роль иконок — каждый раздел имеет постоянный маркер.

| Раздел | Эмодзи | Использование |
|---|---|---|
| Тренировки | 🏋️ | Планы, логи, история тренировок |
| Питание | 🥗 | Планы питания, еда |
| Запись еды | 🍽 | Дневной итог, лог приёма пищи |
| Прогресс | 📊 | Вес, замеры, динамика |
| Мотивация | 💪 | Ободрение, достижения |
| Профиль | 👤 | Данные пользователя |
| Цель | 🎯 | Достижение нормы, результаты |
| Калории | 🔥 | Расход энергии |
| Время | ⏱ | Длительность тренировок |
| Успех | ✅ | Подтверждения действий |
| Ошибка/мягко | ⚠️ | Предупреждения (не ошибки) |
| Главное меню | 🏠 | Кнопка возврата |
| Настройки | ⚙️ | Профиль, настройки |
| Помощь | ❓ | Help, подсказки |

## 5. Компоненты: Inline Keyboards

### 5.1 Главное меню

```
┌─────────────────────────────────────┐
│ Привет, {имя}! Чем займёмся? 💪    │
│                                     │
│  [🏋️ Тренировка]  [🥗 Питание]    │
│  [📊 Прогресс]    [👤 Профиль]     │
│  [💪 Мотивация]                     │
└─────────────────────────────────────┘
```

### 5.2 Меню тренировок

```
┌─────────────────────────────────────┐
│ 🏋️ *Тренировки*                    │
│                                     │
│  [📋 Мой план]                      │
│  [✅ Записать тренировку]           │
│  [📈 История]                       │
│  [🏠 Главное меню]                  │
└─────────────────────────────────────┘
```

### 5.3 Меню питания

```
┌─────────────────────────────────────┐
│ 🥗 *Питание*                        │
│                                     │
│  [📋 Мой план питания]              │
│  [🍽 Итог за сегодня]              │
│  [🏠 Главное меню]                  │

> Кнопки «Записать еду» нет намеренно — пользователь пишет текстом напрямую.
> Это снижает когнитивную нагрузку и делает запись естественной.

```

## 6. Экраны: ключевые сценарии

### 6.1 Онбординг (/start для нового пользователя)

**Шаг 1 — Приветствие**
```
👋 Привет! Я FitnessAI — твой персональный тренер.

Помогу составить план тренировок и питания,
считать калории и следить за прогрессом.

Для начала — пара вопросов. Займёт 1 минуту 🎯
```
→ Кнопка: `[Поехали!]`

**Шаг 2 — Цель**
```
Какая у тебя основная цель?
```
→ Кнопки: `[🔥 Похудение]` `[💪 Набор массы]` `[⚖️ Поддержание формы]`

**Шаг 3 — Активность**
```
Как бы ты описал свою текущую активность?
```
→ Кнопки (вертикально):
```
[🛋 Малоподвижный (офис, почти без спорта)]
[🚶 Умеренный (1–3 тренировки в неделю)]
[🏃 Активный (4–5 тренировок в неделю)]
[🔥 Очень активный (ежедневные тренировки)]
```

**Шаг 4 — Данные (текстовый ввод, по одному)**
```
Сколько тебе лет?
```
```
Какой у тебя рост? (в см, например: 178)
```
```
Какой сейчас вес? (в кг, например: 82.5)
```

**Шаг 5 — Завершение**
```
✅ Отлично, {имя}! Всё готово.

Твоя норма: *2 480 ккал/день*
Белки: 155г · Жиры: 68г · Углеводы: 280г

Хочешь сразу получить план тренировок или план питания?
```
→ Кнопки: `[🏋️ План тренировок]` `[🥗 План питания]` `[🏠 Главное меню]`

---

### 6.2 Свободный диалог (основной режим)

Пользователь пишет текстом — агент понимает намерение и вызывает нужный инструмент.

**Примеры входных фраз → реакция:**

| Фраза пользователя | Действие агента |
|---|---|
| «съел овсянку 200г и яйцо» | `log_food` → карточка записи + дневной итог |
| «сколько я сегодня съел?» | `get_daily_nutrition_summary` → итог с прогресс-баром |
| «дай план тренировки» | `generate_workout_plan` → карточка плана |
| «записал тренировку, 45 минут» | `log_workout` → подтверждение + мотивация |
| «сколько вешу в динамике?» | `get_progress_summary` → сводка с дельтой |
| «мотивируй меня» | `send_motivation` → персональное сообщение |

### 6.3 Запись еды (ключевой сценарий)

**Пользователь пишет:** `"поел: гречка 150г, куриная грудка 200г, салат"`

**Бот отвечает:**
```
✅ *Записано*

🍽 Обед · 18 мая, 14:32

• Гречка варёная 150г — 190 ккал · Б 7г · Ж 2г · У 38г
• Куриная грудка 200г — 220 ккал · Б 46г · Ж 2г · У 0г
• Салат (овощи) 100г — 25 ккал · Б 1г · Ж 0г · У 5г

*Итого:* 435 ккал · Б 54г · Ж 4г · У 43г

_День: 1 240 / 2 480 ккал_ ██████░░░░ 50%
```

### 6.4 Сообщение об ошибке

```
⚠️ Не смог разобрать продукт: «сосиска с чем-то».

Попробуй написать точнее, например:
_«сосиска молочная 2 шт (80г)»_
```

### 6.5 Мотивационное сообщение

```
💪 *Асан, ты на верном пути!*

Уже {N} дней подряд ты закрываешь норму по белку —
это реальный прогресс, даже если весы ещё молчат.

Сегодня: {workout/rest day phrase}

_Маленькие шаги каждый день — это и есть результат._
```

## 7. Навигация: общие правила

1. **Главное меню** доступно из любой точки бота — кнопка `🏠 Главное меню` или команда `/menu`
2. **Назад** — там, где есть подменю, первая или последняя кнопка — возврат
3. **Выход из FSM** — всегда `/menu` или `/start` прерывает онбординг/любой flow
4. **Команды-шорткаты:**

| Команда | Действие |
|---|---|
| `/start` | Онбординг (новый) или главное меню (существующий) |
| `/menu` | Главное меню |
| `/plan` | Последний план тренировки |
| `/nutrition` | План питания |
| `/progress` | Сводка прогресса |
| `/today` | Итог питания за сегодня |
| `/clear` | Сбросить историю диалога |

## 8. Адаптивность и edge cases

| Ситуация | Поведение |
|---|---|
| Пользователь шлёт голосовое | Транскрибируем → обрабатываем как текст, отвечаем: _«(голосовое расшифровано)»_ перед ответом |
| Пользователь шлёт фото еды | Агент описывает блюдо и предлагает записать: «Вижу пасту с курицей. Записать?» |
| Длинный ответ агента | Разбивать на 2–3 сообщения, не один монолит |
| Markdown не рендерится | Fallback на plain text (уже реализован в chat.py) |
| Пользователь пишет на другом языке | Отвечаем на том же языке (системный промпт задаёт правило) |

## 9. Чего не делать (анти-паттерны)

| Анти-паттерн | Почему плохо | Альтернатива |
|---|---|---|
| «Ваш запрос обрабатывается» | Канцелярит, нет ощущения живого бота | «Смотрю...» или просто ответ |
| Кнопка «Записать еду» | Лишний шаг, дублирует текстовый ввод | Пользователь пишет напрямую |
| Два вопроса в одном сообщении | Непонятно на что отвечать | Один вопрос — одно сообщение |
| Полное КБЖУ без контекста | Числа без смысла | Всегда показываем % от нормы |
| Ответ без следующего шага | Пользователь теряется | Всегда есть подсказка или кнопка |
| Технические ошибки в чат | Пугает пользователя | Перехватываем → человекочитаемое |
