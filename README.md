# FitnessAI — База знаний проекта

## Описание
Telegram-бот с AI-агентом для персонального фитнес-коучинга.
Агент помнит пользователя, составляет планы тренировок и питания, отслеживает прогресс, считает КБЖУ, мотивирует.

## Разделы базы знаний

| Файл | Описание |
|------|----------|
| [[context]] | Архитектура, стек, ключевые решения |
| [[structure]] | Структура кодовой базы |
| [[database]] | Схема БД, таблицы, связи |
| [[tools]] | Инструменты агента (описание, сигнатуры) |
| [[daily-changes]] | Лог изменений по датам |

## Стек
- **Бэкенд:** Python, aiogram 3, LangGraph
- **Модель (dev):** Ollama — qwen2.5:7b
- **Модель (prod):** Gemini API (бесплатный tier)
- **БД:** Supabase (PostgreSQL)
- **Платформа:** Telegram Bot

## Для агентов
- При получении任务 первым делом читай этот файл, затем переходи по ссылкам к нужному разделу
- При любом изменении кода обновляй [[structure]] и [[daily-changes]]
- При изменении схемы БД обновляй [[database]]
- При добавлении нового инструмента обновляй [[tools]]
- Не дублируй информацию — ссылайся на существующие разделы
